# Iris Flower Analysis Dashboard

## Project Overview
Analyzed the Iris dataset (150 flowers, 3 species) using Microsoft Power BI to understand differences between species based on sepal and petal measurements.

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Dataset
- Source: Kaggle (Iris Dataset)
- 150 rows, 3 species (Setosa, Versicolor, Virginica)
- 4 measurements: Sepal Length, Sepal Width, Petal Length, Petal Width

## Key Insights
1. All 3 species have equal count (50 each)
2. Virginica has the largest average sepal length
3. Setosa has the smallest average petal length
4. The dataset is perfectly balanced (no class imbalance)

## Dashboard Features
- Bar Chart: Average Sepal Length by Species
- Pie Chart: Species Distribution
- Cards: Average Petal Length, Average Sepal Length
- Slicer: Filter by Species
